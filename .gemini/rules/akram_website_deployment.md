# GitHub Pages Deployment & Build Architecture for akram1871.github.io

## CRITICAL INVARIANT: Never commit raw JSX entry in root index.html

### 1. Root Cause of White Page / Blank Screen
- The repository `akram1871.github.io` serves GitHub Pages directly from the `main` branch root directory (`/`).
- Standard web browsers cannot natively execute raw JSX, React components, or unbundled bare module specifiers (e.g. `import React from 'react'`).
- If `index.html` at the repository root contains:
  `<script type="module" src="/src/main.jsx"></script>`
  the live browser will throw:
  `Uncaught SyntaxError: Unexpected token '<'` (or bare specifier error) and render an empty white page.

### 2. Mandatory Production Bundle Rule
- The root `index.html` MUST ALWAYS point to the compiled production bundle generated by Vite in the `/assets/` directory:
  ```html
  <script type="module" crossorigin src="/assets/index-[hash].js"></script>
  <link rel="stylesheet" crossorigin href="/assets/index-[hash].css">
  ```
- The corresponding bundled files (`assets/index-[hash].js` and `assets/index-[hash].css`) MUST be committed in the root `assets/` directory alongside `index.html`.

### 3. Build & Sync Procedure (Automated via scripts/build.js)
Whenever making source changes to `src/`:
1. Use an automated build script (`npm run build` configured via `node scripts/build.js`):
   - Step A: Temporarily copy/write the development entry `index.template.html` (with `/src/main.jsx`) to `index.html`.
   - Step B: Execute `npx vite build` to compile the app into `dist/`.
   - Step C: Copy `dist/index.html` back to root `index.html`.
   - Step D: Copy `dist/assets/*` to root `assets/`.
2. This guarantees that `index.html` at the root is ALWAYS pointing to the latest production bundle with the exact hashed filenames.
3. In `App.jsx`, ALWAYS maintain a fallback route:
   `<Route path="*" element={<MainPortfolio />} />`
   so that any unexpected hash (e.g. `#teaching`, `#publications`, `#about`) will gracefully render the main portfolio rather than an empty screen.
